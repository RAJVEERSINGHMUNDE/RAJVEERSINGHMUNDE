### About Me

- Reimplement things people usually just import — wrote my own **Redis** in Go, a **CPU renderer** hand-tuned with AVX2 intrinsics, and a **GPU from scratch in SystemVerilog**
- Into the layer where software meets hardware: RTL, network-on-chip simulation, and performance-critical C/Go
- Also dabble on the other end of the stack — quant/fintech tooling in Python and a Flutter mobile app
- Always mid-way through a project that's "just for fun, to see how it works under the hood"
